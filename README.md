# Online-Store-Analysis

Online Store Sales Dashboard — Excel Project
1. Project Overview
Project Name: Online Store Sales Dashboard  
Tool Used: Microsoft Excel  
Domain: E-commerce / Online Retail  
Analysis Type: Sales and Order Performance Analysis
The Online Store Sales Dashboard is an Excel-based business intelligence dashboard created to understand online store performance through sales, orders, product performance, payment methods, order status, referral sources, and customer shopping activity.
The dashboard converts raw online order data into easy-to-read KPIs, charts, and interactive filters so that users can quickly understand sales performance and order behavior.
---
2. Business Objective
The main objective of this project is to:
Monitor total sales generated by the online store.
Track total quantity sold and total orders.
Understand items added to customer carts.
Compare sales across different products.
Analyze sales by payment method.
Understand the distribution of order statuses.
Compare sales generated through different referral sources.
Track sales performance across years.
Allow users to filter the dashboard by product and quarter.

8. Key Dashboard Observations
The dashboard provides several useful observations from the available dataset:
The store records 1,200 orders with a total sales value of 1,264,761.96.
Chair and Printer have very similar sales values and are among the highest-selling products by sales value.
Phone has the lowest sales value among the seven products shown.
Credit Card has the highest sales value among the five payment methods.
Debit Card has the lowest sales value among the payment methods.
Instagram generates the highest sales value among the listed referral sources.
Referral has the lowest sales value among the referral sources.
The yearly data shows the highest sales value in 2023, followed by 2024.
The 2025 value is lower than previous years, but the dataset only contains January–June 2025, so it should not be compared with full-year totals without considering the different time coverage.
The order-status chart shows that sales value is spread across cancelled, pending, shipped, returned, and delivered orders, making order-status monitoring important for the store.

9. Excel Analysis Process
The project can be described through the following workflow:
```text
Raw Online Store Data
        ↓
Data Cleaning & Preparation
        ↓
Data Validation
        ↓
Pivot Tables / Calculations
        ↓
KPI Creation
        ↓
Charts & Visualizations
        ↓
Interactive Filters
        ↓
Online Store Sales Dashboard
```
Step 1 — Data Collection
The project starts with order-level online store data containing customer, product, payment, order-status, referral, coupon, and sales information.
Step 2 — Data Preparation
The data is checked for:

Consistent payment methods
Consistent order statuses
Step 3 — Data Analysis
Excel calculations and PivotTables are used to summarize:
Total sales
Total quantity
Total orders
Items in cart
Product sales
Payment method sales
Order status sales
Referral source sales
Yearly sales
Step 4 — Dashboard Creation
The summarized information is presented using KPI cards, pie charts, bar charts, and a line chart.
Step 5 — Interactivity
Product and quarter filters allow users to change the dashboard view dynamically.

15. Important Data Considerations
The `TotalPrice` field is treated as the sales-value measure in this dashboard.
The dataset contains 1,200 unique orders.
2025 is a partial year in the available data, ending in June.
Yearly comparisons should consider the different number of months available.
Order status and sales value should be interpreted together because cancelled and returned orders also have recorded `TotalPrice` values in the dataset.
The dashboard is intended for descriptive business analysis and reporting.
